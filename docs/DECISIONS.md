| 2026-11-11 | `/v1/ask` calls Claude only when `ANTHROPIC_API_KEY` is set, and otherwise returns 503. The dense abstain floor is cosine **0.35**. Reported cost uses $3 / $15 per million input / output tokens, overridable with `SSV2_INPUT_USD_PER_MILLION` and `SSV2_OUTPUT_USD_PER_MILLION` | No key was available in this environment, so the live messages API was not called. The client and the stream parser are covered with a fake transport. Hybrid and rerank scores are not cosine, so they ignore the floor and abstain only when retrieval returns nothing | A fake answer in production when the key is missing; one floor for every retriever |
| 2026-11-11 | Keep dense retrieval as the default. Hybrid RRF and a cross-encoder reranker are available via `SSV2_RETRIEVER` but are not the default | Same 300 SciFact test queries, 0-1 scale. Dense stayed at nDCG@10 **0.7127**, recall@10 **0.8362**, MRR@10 **0.6822**. Hybrid (BM25 + dense, RRF k=60, pool 100) scored **0.7085 / 0.8247 / 0.6777**. Reranking the dense top 30 with `cross-encoder/ms-marco-MiniLM-L6-v2` at `233902d25c440f23af6f7d6e94d2946bac0bee0a` scored **0.7039 / 0.8352 / 0.6692**. Both are under the dense score, so neither replaces it | Adopting hybrid or rerank because they are "usually" better; lowering the floor |
| 2026-11-11 | arXiv ingestion keeps a paper only when its license URL is CC BY 4.0, and the default slice is categories starting with `cs.` The download is shard `data/train-00000-of-00011.parquet` of `librarian-bots/arxiv-metadata-snapshot` at `c428226b689a0e17db2cd55265133b9eca15d97f`, capped at 2,000 papers | The metadata snapshot is CC0, but the abstract text is under the paper's own license. That shard is the recent one: it holds the CC BY 4.0 papers (about 62,000 in cs). Older shards in this snapshot only have CC BY 3.0. The cap keeps a local index small | Indexing every arXiv abstract; trusting a dataset card that says CC BY 4.0 for the whole collection |
| 2026-11-11 | Search p95 is measured by `ssv2 bench` / `make bench`, and it is not a CI gate. On this machine, 50 warmed SciFact searches (k=10) had p50 **8.7 ms** and p95 **9.6 ms**, under the 200 ms MVP budget | Embedding one query dominates, and a shared CI runner's p95 moves around enough to flap. The number is recorded here instead | Failing CI at 200 ms (noisy); no measurement |

The floor is 0.03 under the measured nDCG so noise does not fail CI and a real drop does. `make eval` enforces the same constant | A floor under the published number instead of the measured one; no floor until more runs |

| 2026-11-11 | Trivy runs from a digest-pinned container via `make scan`, not `aquasecurity/trivy-action` | Same command locally and in CI (a CLAUDE.md rule); one less third-party action running in CI (a hijacked action tag, as with tj-actions/changed-files in March 2025, runs with the job's token and secrets) | trivy-action pinned to a SHA (fine, but not runnable through `make`); Docker Scout (needs a Docker login) |
| 2026-11-11 | `apt-get upgrade` in the runtime stage | The first scan found two HIGH zlib CVEs already fixed in Debian but not yet in the official python image. Upgrading closes that gap; once upstream rebuilds, Dependabot bumps the digest and the step is a no-op. Cost: OS packages depend on build day, not only on the digest | Wait for upstream (ships a known-fixable CVE); `.trivyignore` with an expiry date (hides it); distroless or Chainguard base (smaller, but harder to debug while learning) |
| 2026-11-11 | 7-day supply-chain cooldown: `exclude-newer = "7 days"` in pyproject.toml, `cooldown: 7` days in Dependabot, and the same rule for the uv, Trivy and action versions picked | Most malicious or broken releases are caught and yanked within days; a relative span keeps `uv lock --check` stable, unlike a fixed date | No cooldown (fastest updates, most exposure); a fixed `exclude-newer` date (blocks Dependabot) |
| 2026-11-11 | Everything pinned by hash: actions by commit SHA, base images (`python:3.12-slim-trixie`, `uv`, Trivy) by digest, pre-commit hooks by frozen SHA, ruff in pre-commit via `uv run` (so its version comes from uv.lock) | Tags can be moved to point at different code; hashes can't. One ruff pin instead of two that drift | Version tags (readable, mutable) |
| 2026-11-11 | Startup work (Phase 1: loading the model and index, checking the manifest) blocks in the FastAPI lifespan; `/ready` is 503 before startup and during shutdown | Fail fast: a model mismatch stops the process at startup instead of leaving a live, wrong service. uvicorn doesn't accept connections until startup finishes | Load in a background thread so `/health` answers during a slow load (needed only if startup ever outgrows the platform's probe timeout) |
| 2026-11-11 | mypy `--strict` with the pydantic plugin as the type checker | Pure Python (installs from PyPI with no Node runtime download in CI), first-class Pydantic support, the most widely used checker | pyright (faster, but its PyPI wrapper fetches Node at runtime); ty (too new to rely on) |
