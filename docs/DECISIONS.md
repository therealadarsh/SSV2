# Decisions log

Newest first. Add a row whenever a choice would be hard to reverse or someone might later
ask "why did we do it this way?". Eval-driven decisions must cite the scorecard numbers.

| Date | Decision | Why | Alternatives considered |
| --- | --- | --- | --- |
| 2026-11-11 | Separate `typecheck` CI job and required check (alongside `lint`, `test`, `docker`) | A red `typecheck` says exactly what broke; it runs in parallel with lint and tests, so it costs no wall time | Fold mypy into `lint` (keeps three check names, but mixes two kinds of failure) |
| 2026-11-11 | Trivy runs from a digest-pinned container via `make scan`, not `aquasecurity/trivy-action` | Same command locally and in CI (a CLAUDE.md rule); one less third-party action running in CI (a hijacked action tag, as with tj-actions/changed-files in March 2025, runs with the job's token and secrets) | trivy-action pinned to a SHA (fine, but not runnable through `make`); Docker Scout (needs a Docker login) |
| 2026-11-11 | `apt-get upgrade` in the runtime stage | The first scan found two HIGH zlib CVEs already fixed in Debian but not yet in the official python image. Upgrading closes that gap; once upstream rebuilds, Dependabot bumps the digest and the step is a no-op. Cost: OS packages depend on build day, not only on the digest | Wait for upstream (ships a known-fixable CVE); `.trivyignore` with an expiry date (hides it); distroless or Chainguard base (smaller, but harder to debug while learning) |
| 2026-11-11 | 7-day supply-chain cooldown: `exclude-newer = "7 days"` in pyproject.toml, `cooldown: 7` days in Dependabot, and the same rule for the uv, Trivy and action versions picked | Most malicious or broken releases are caught and yanked within days; a relative span keeps `uv lock --check` stable, unlike a fixed date | No cooldown (fastest updates, most exposure); a fixed `exclude-newer` date (blocks Dependabot) |
| 2026-11-11 | Everything pinned by hash: actions by commit SHA, base images (`python:3.12-slim-trixie`, `uv`, Trivy) by digest, pre-commit hooks by frozen SHA, ruff in pre-commit via `uv run` (so its version comes from uv.lock) | Tags can be moved to point at different code; hashes can't. One ruff pin instead of two that drift | Version tags (readable, mutable) |
| 2026-11-11 | Startup work (Phase 1: loading the model and index, checking the manifest) blocks in the FastAPI lifespan; `/ready` is 503 before startup and during shutdown | Fail fast: a model mismatch stops the process at startup instead of leaving a live, wrong service. uvicorn doesn't accept connections until startup finishes | Load in a background thread so `/health` answers during a slow load (needed only if startup ever outgrows the platform's probe timeout) |
| 2026-11-11 | mypy `--strict` with the pydantic plugin as the type checker | Pure Python (installs from PyPI with no Node runtime download in CI), first-class Pydantic support, the most widely used checker | pyright (faster, but its PyPI wrapper fetches Node at runtime); ty (too new to rely on) |
| 2026-11-11 | CPU-only torch from the PyTorch index on Linux via `[tool.uv.sources]`, PyPI torch on macOS; lock limited to linux x86_64/aarch64 and macOS arm64 | PyPI's Linux torch pulls in several GB of CUDA libraries we never use; the lockfile stays small and resolvable | `--index-url` flags in Docker and Make (not recorded in the lockfile); CUDA wheels (needs a GPU) |
| 2026-11-11 | Phase 0 locks the ML stack (torch, sentence-transformers, faiss-cpu) before any code imports it | Proves the CPU-only PyTorch setup and shows the real image size (460 MB compressed) now, before Phase 1 depends on it | Add the ML stack in Phase 1 (smaller image now, surprises later) |
| 2026-11-11 | Release workflow publishes only; Semantic-Search's deploy job is not carried over | No host has been chosen, and a disabled deploy job is untested code. Re-add it when a host is picked | Copy it behind `DEPLOY_ENABLED` |
| 2026-11-11 | Python 3.12, FastAPI, `uv` with a committed lockfile, `src/` layout | Familiar from Semantic-Search; a lockfile pins transitive dependencies; `src/` stops tests from accidentally importing the working tree | Plain requirements.txt (no transitive pins); Poetry (slower, less common now) |
| 2026-11-11 | In-memory FAISS flat index for the MVP | Corpora are under 100 MB of vectors; exact search is fast and simple | pgvector or Qdrant (needed later for live updates or more than ~1M docs) |
| 2026-11-11 | Embedding model `BAAI/bge-small-en-v1.5`, pinned to a revision | MIT license, 384 dimensions, runs well on CPU, strong on BEIR | all-MiniLM-L6-v2 (weaker); larger models (slower on CPU). Revisit using eval numbers. |
| 2026-11-11 | SciFact (BEIR) for evaluation; arXiv CS slice (CC BY 4.0 papers only) as the realistic corpus | SciFact has expert relevance labels and published baselines; arXiv metadata is CC0, current, and has dates and categories | AG News (non-commercial, 2004); MS MARCO (non-commercial, large); Wikipedia (share-alike) |
| 2026-11-11 | Start a new repo instead of evolving Semantic-Search | A clean design with no legacy scripts; Semantic-Search stays as the reference | Evolve in place (keeps history but drags old structure along) |
